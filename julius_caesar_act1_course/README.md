# Julius Caesar — Act 1 Master Course & Study Book (ICSE)

- `JuliusCaesar_Act1_MasterCourse_ICSE.pdf` — the complete study book (643 A4 pages, 23 chapters, ~350,000 words), with clickable contents and PDF bookmarks.
- `chapters_markdown/` — the chapter sources.
- `build/` — the build pipeline (Markdown → HTML → Chromium PDF), the quotation checker that compares every quotation against the Folger and Globe texts, and the fact brief the chapters were written from.

Note on syllabus: Act 1 is the Class IX portion of the ICSE Julius Caesar syllabus; the Class X board paper examines Acts III–V but depends on Act 1 throughout. See the front matter.
